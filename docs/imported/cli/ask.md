# dendrite ask

Ask questions to Dendrite about a project with local RAG and interactive paid fallback

## Category

Cortex & Sensory Integration

## Aliases

- `query-project`
- `rag-ask`
- `q`

## Subcommands

None

## Flags

| Flag | Description |
| :--- | :--- |
| `--paid-fallback` | Fallback to commercial paid model when local model fails |

## Examples

```bash
dendrite ask "How does token budget governance work in Dendrite?"
```
